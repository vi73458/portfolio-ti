# GestãoFácil ERP

ERP acadêmico e independente para demonstrar conceitos de sistemas corporativos.

## Funcionalidades planejadas
- Cadastro de produtos
- Clientes e fornecedores
- Entradas e saídas de estoque
- Pedidos de venda
- Alertas de estoque baixo
- Relatórios operacionais

## Fluxo principal
`Produto → Estoque → Pedido → Baixa → Relatório`

> Projeto autoral, sem vínculo com marcas ou produtos proprietários.
