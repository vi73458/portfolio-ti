# Portfólio TI — Victor Hugo

Coleção de projetos independentes para demonstrar habilidades em **Suporte de TI, Service Desk, operações, sistemas corporativos e desenvolvimento web**.

> Os projetos são autorais e inspirados em cenários comuns do mercado. Não possuem vínculo oficial com Positivo, TOTVS ou Stefanini.

## Projetos

### 1. SupportDesk
Sistema de gerenciamento de chamados de Service Desk.
- Incidentes e requisições
- Prioridades e status
- Diagnóstico e histórico
- Dashboard operacional
- Java 17, Spring Boot, React, TypeScript e PostgreSQL

### 2. TechCare
Gestão de assistência técnica e equipamentos.
- Cadastro de clientes e equipamentos
- Ordens de serviço
- Diagnóstico de hardware e software
- Controle de garantia e reparos

### 3. GestãoFácil ERP
ERP simplificado para rotinas administrativas.
- Produtos e estoque
- Clientes e fornecedores
- Pedidos e movimentações
- Alertas de estoque baixo

### 4. IT Operations Center
Central de operações de TI.
- Incidentes e indisponibilidades
- SLA e prioridades
- Monitoramento de serviços
- Escalonamento e indicadores

### 5. BaseTI
Base de conhecimento para suporte.
- Artigos e procedimentos
- Busca por problemas
- Categorias e tags
- Guias de troubleshooting

## Objetivo
Demonstrar raciocínio de resolução de problemas, organização de processos, documentação técnica, integração entre sistemas e desenvolvimento de aplicações.

## Status
Os módulos estão sendo construídos progressivamente, priorizando MVPs funcionais, documentação e evolução incremental.
