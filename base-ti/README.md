# BaseTI

Base de conhecimento para apoiar atendimento e troubleshooting de TI.

## Funcionalidades planejadas
- Artigos técnicos
- Categorias e tags
- Pesquisa por sintomas e palavras-chave
- Procedimentos passo a passo
- Artigos mais acessados
- Registro de solução aplicada

## Estrutura sugerida de artigo
1. Título do problema
2. Sintomas
3. Causa provável
4. Procedimento de diagnóstico
5. Solução
6. Evidências e observações
